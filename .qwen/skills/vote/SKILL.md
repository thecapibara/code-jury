# 🎭 Vote Skill - Система Журі

Подібно до America's Got Talent — 4 незалежних судді оцінюють код!

## Як це працює

1. Визначається мова користувача з контексту
2. Генерується 4 судді з унікальними іменами та характерами
3. Кожен суддя паралельно оцінює код
4. Вердикт: Так/Ні з балами та порадами

## Команди

Запусти головний скрипт з потрібними аргументами:

```bash
python3 scripts/vote.py [аргументи]
```

### Доступні аргументи

| Аргумент | Опис |
|----------|------|
| (без аргументів) | Незакомічені зміни або поточна гілка |
| `--commit HEAD` | Останній коміт |
| `--last N` | Останні N комітів |
| `--branch <ім'я>` | Зміни гілки відносно main |
| `--file <файл>` | Оцінити один файл |
| `--staged` | Staged зміни |
| `--diff <файл>` | Diff з файлу |
| `--history` | Історія голосувань |
| `--session <id>` | Результати сесії |

## Структура

```
vote/
├── SKILL.md (цей файл)
├── scripts/
│   ├── vote.py                   # Головний скрипт
│   ├── judge_coordinator.py      # Координація журі
│   ├── language_detector.py      # Визначення мови
│   ├── branch_tracker.py         # Трекінгу issues на гілці
│   └── judge_profiles/           # Профілі для 9 мов
├── sessions/                     # Кеш сесій (не комітиться)
└── branches/                     # Історія гілок (не комітиться)
```
